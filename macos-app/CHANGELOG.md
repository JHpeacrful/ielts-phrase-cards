# 更新说明

## 2026-09-09 · AI 生成确认与字段约束

- 点击字段旁的 AI 按钮时只打开工作台，不再自动发起生成请求；必须点击“生成内容”后才会调用 API。
- 固定搭配/语法框架字段严格只返回结构模板，禁止完整例句、中文解释和 Markdown。
- 原创句子字段要求一次返回一行口语句和一行书面句，按 IELTS 7-8 分段控制表达质量。
- 增加生成结果校验：固定搭配疑似返回例句时拒绝应用；原创句子缺少两行标签时要求重新生成。

## 2026-09-08 · macOS App 分区导航与概览

- 新增固定顶部五标签导航：概览、学习、复习、历史、设置；窄窗口自动收缩为当前页面下拉菜单。
- 新增概览页，展示全部卡片、今日到期、G 卡、今日复习进度和连续学习天数。
- 将短语填写、到期复习、卡片库历史、外观/AI/数据备份拆分到独立视图；切换标签不会清除未保存表单内容。
- 复习页只显示今日到期卡，保留现有正反面、左右切换和 R/Y/G 评分算法；新增本地评分日志用于进度和连续学习统计。

## 2026-09-03 · macOS App 图标更新

- 更换默认 Electron 原子图标，改为打开的短语卡与对话气泡图标。
- 使用高分辨率 PNG 作为源素材，由 Electron Builder 生成并嵌入 macOS `icon.icns`。

## 2026-09-03 · 模型列表获取

- AI 设置新增“获取模型”按钮，调用当前 API 的 `/models` 接口并展示可选择的模型列表。
- 选择模型后自动填入模型名称；接口不支持或请求失败时保留原模型并显示错误原因。

## 2026-09-03 · macOS App 0.2.0 · AI 字段工作台

- 将单一 AI 补全按钮升级为字段级 AI 入口：个人化提示、英文释义、搭配/框架和原创句子均可单独生成或改写。
- 支持选中文字后只修改选区；没有选区时作用于整个字段。结果先预览，点击“应用结果”后才写回，并支持撤销上次应用。
- 增加生成、改写、重新生成、缩短、展开和 IELTS 表达等操作。
- AI 设置支持保存多条 API/模型配置，工作台内可直接切换；旧单配置会自动迁移。
- “短语”字段保持手动输入，不提供 AI 自动替换。

## 2026-09-03 · macOS App 0.1.0

- 用 Electron 封装现有 IELTS 短语卡网站，保留离线保存、复习正反面、左右导航、深色模式和导入导出。
- 增加“AI 设置”弹窗，支持自定义 OpenAI 兼容 API 地址、模型名称和 API Key。
- 增加 API 连接测试和“AI 补全释义与例句”按钮。
- API Key 仅保存在本机 App 数据目录，不进入源码或备份文件。
- 提供 Apple Silicon macOS `.app` 打包配置。
