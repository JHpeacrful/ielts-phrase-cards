# IELTS Phrase Cards

把“看过”变成“说得出来”。这是一个离线优先的 IELTS 英式短语卡工具：你亲自输入想掌握的表达，用个人化提示建立记忆钩子，再用间隔复习把它们带进写作和口语。

网页版可以直接打开，macOS App 则提供更完整的分区工作流和可选 AI 工作台。数据默认保存在本机，学习节奏由你掌控。

## 直接使用

- [打开 GitHub Pages 网页版](https://jhpeacrful.github.io/ielts-phrase-cards/)
- [双语工具说明](./TOOL_README.md)
- [五周学习执行方案](./STUDY-PLAN.md)
- [更新说明](./CHANGELOG.md)

网页版不需要注册，也不依赖服务器。第一次使用时，建议先导出一份 JSON 备份。

## 五个页面，五种专注

macOS App 顶部固定导航，把原本拥挤的一页拆成五个工作区：

- **概览**：先看今天该做什么。全部卡片、今日到期、G 卡数量、今日完成进度和连续学习天数一眼可见。
- **学习**：只负责填写和编辑卡片。短语由你自己输入；个人化提示、英文释义、搭配框架和原创句子可以按需调用 AI。
- **复习**：只显示当前词库的今日到期卡，沿用 R / Y / G 评分算法。正面先回忆，翻到背面核对，左右切换卡片，评分后自动安排下一次复习；正反面都可以收藏。
- **历史**：卡片库的完整视图。支持“全部卡片 / 收藏夹”子标签、搜索、用途筛选、状态筛选、词库筛选、编辑和删除。
- **设置**：把外观、AI 配置、词库管理、每日文案和数据备份集中管理。窄窗口会自动收缩为当前页面下拉菜单。

## 一张卡片怎么写

一张卡只保留真正有用的内容：

1. **英文短语**：写下你想主动使用的表达。
2. **个人化提示**：例如 `Education: school subjects`，让回忆有入口。
3. **英文释义**：用短而准确的英文解释，不抄中文释义。
4. **固定搭配 / 语法框架**：记录它在句子里怎么站得住。
5. **我的原创句子**：把表达放进你自己的语境。
6. **用途与状态**：标记 W（写作）、S（口语）或 WS，并用 G / Y / R 反映真实掌握程度。

## 复习算法

- `G`：能自主造句，进入更长间隔。
- `Y`：需要提示，次日再次出现。
- `R`：想不出或用错，重置为优先复习。

复习队列优先处理 R 卡，再按到期日期排序。当天已经评分的卡片会记录到本地学习日志，用于计算今日进度和连续学习天数；不会上传到网络。

## AI 工作台（可选）

macOS App 支持多个 OpenAI 兼容 API 配置。每条配置可以填写：

- API 地址，例如 `https://api.example.com/v1`
- 模型名称
- API Key

在设置中点击“获取模型”即可读取服务商的 `/models` 列表并切换模型。编辑卡片时，字段旁的 AI 入口支持：

- 生成候选
- 改写当前内容
- 选中一段文字后只修改选区
- 重新生成、缩短、展开或调整为 IELTS 表达

AI 结果只会先出现在预览区，点击“应用结果”后才写回字段；“短语”字段始终由你手动输入，不会被 AI 自动替换。

API Key 只保存在当前 Mac 的 Electron 用户数据目录，不进入源码、Git 提交或短语卡 JSON 导出文件。

## 多词库与导入

一张卡可以同时属于多个词库，词库之间拥有独立的复习进度；同名短语放在不同词库中也会分别保留。普通导入支持 JSON、CSV 和 TXT，导入前可选择已有词库或输入名称新建词库；选择已有词库时会替换该词库内容，其他词库保持独立。macOS App 还支持粘贴网页文字交给 AI 整理：AI 会提取可能的短语、补全缺失字段，并先生成可编辑预览；无法确定的内容标为“待确认”，确认后才会新建词库。

## macOS App

源码位于 [`macos-app/`](./macos-app/)：

```bash
cd macos-app
npm install
npm start
```

构建 Apple Silicon 版本：

```bash
npm run dist
```

构建产物会出现在 `macos-app/dist/mac-arm64/IELTS Phrase Cards.app`。本仓库只提交 App 源码，不提交约 257 MB 的 Electron `.app` 二进制，以避免超过 GitHub 的单文件大小限制。需要可运行版本时，在本地执行上面的构建命令即可。

当前 App 未使用 Developer ID 签名和公证。分发给其他 Mac 前，请使用自己的 Apple Developer 账号完成签名、公证和 DMG 打包。

## 数据与迁移

网页版与 macOS App 都使用 JSON 卡片结构。换设备或清理浏览器 / App 数据前，请在历史或设置页面导出备份；导入时会与现有卡片合并。

本项目坚持一个简单标准：卡片不是收藏夹，而是下一次写作或开口时能被准确调取的表达资源。
